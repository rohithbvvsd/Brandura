# Images Folder — Brandura Website

Your images live here. The website automatically uses these files:

| File Name          | Where It's Used                     | Notes                                      |
|--------------------|-------------------------------------|--------------------------------------------|
| `logo.jpeg`        | Navbar + Footer logo                | Already added ✓                            |
| `founder.jpeg`     | Founder section (Rohit)             | Already added ✓                            |
| `hero-main.jpg`    | Homepage hero (main visual)         | Already added ✓ (portrait 4:5)              |
| `about.jpg`        | About section                       | Already added ✓ (portrait)                  |

**Notes:**
- JPG, PNG or WebP all work. If `hero-main.jpg` / `about.jpg` are missing, the site shows a styled fallback card instead — design never breaks.
- Recommended resolution: at least `800×1000px` for crisp display.
- Extra assets can go in the `assets/` folder.
