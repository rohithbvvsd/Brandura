# Brandura — Creative Digital Agency Website

A modern, fully responsive single-page website built for **Brandura**, a creative digital agency in Vijayawada.

## Sections
- **Home** — Hero with animated stats, floating cards and creative background
- **About** — Studio intro with features
- **Services** — 4 core services (Social Media, Websites, Reel/Ad shoot, Podcast)
- **Founder** — Founder (Rohit) profile with photo & quote
- **Contact** — Contact info + WhatsApp / Instagram / Email buttons

## How to Run
Simply open `index.html` in any browser. No build tools or server required.

## Project Structure
```
Brandura-Website/
├── index.html          → Main webpage
├── css/
│   └── style.css       → All styles (responsive)
├── js/
│   └── main.js         → Navigation, animations
├── images/             → Brand images (see images/README.txt)
└── assets/             → Extra assets
```

## Images
Add these to `images/` with exact names (see `images/README.txt`):
- `logo.jpeg` — used in navbar + footer
- `founder.jpeg` — used in the Founder section
- `hero-main.jpg` — optional hero visual (fallback shown if missing)
- `about.jpg` — optional about visual (fallback shown if missing)
